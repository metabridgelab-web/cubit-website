# 디자인 검토 (design 폴더 10개 파일)

> 검토일: 2026-10-23 · 기준: docs/사이트맵.md (v3)

## 1. 디자인 시스템 (공통으로 잘 잡힌 것)

| 항목 | 내용 |
|---|---|
| 분위기 | 검은 배경 + 홀로그램 · HUD(조종석 화면) 느낌의 메타버스 스타일 |
| 색 | 배경 `#000000` · 시안 `#00f3ff` · 핑크 `#ff00e5` · 라임 `#d4ff00` · 유리 느낌의 반투명 테두리 |
| 글꼴 | Inter(300/500/700/900) + Space Mono(작은 정보 글자) |
| 효과 | 스캔라인, 떠다니는 입자, 무지개빛 버튼, 마우스를 따라 움직이는 글자 |
| 아이콘 | Phosphor Icons |

10개 화면이 같은 색·글꼴·효과를 써서 **한 사이트로 보이는 것은 아주 좋습니다.**

## 2. 화면별 확인

| 파일 | 사이트맵 대응 | 상태 |
|---|---|---|
| 01 홈 첫 화면 | 홈 메인 영상 슬라이드 | ✅ 화면 전체 영상 · 하단 캡슐 메뉴 · 아티스트 미리보기 패널 |
| 02 메뉴 열림 | 전체 화면 메뉴 | ✅ 왼쪽 큰 메뉴 + 오른쪽 포털 미리보기 |
| 03 아티스트 목록 | ARTISTS | ✅ |
| 04 아티스트 상세 | ARTISTS 상세 | ✅ 사진 · 정보 · 자기소개 · 사진 모음 · 뮤직비디오 · 견적 버튼 |
| 05 브랜드·레이블·계열사 | COMPANY | ✅ (2차 오픈 화면) |
| 05 캠페인 빌더 | BUSINESS ★필수 | ✅ 5단계 + 오른쪽 요약 |
| 06 STUDIO | STUDIO | ✅ (2차 오픈 화면) |
| 07 토큰 정보 | INVESTORS | ✅ (3차 오픈 화면) |
| 08 뉴스 목록 | NEWS | ✅ 고정 글 · 분류 |
| 09 CONTACT | CONTACT | ✅ 캠페인 빌더 안내 + 문의 양식 + 사무실 |

## 3. 고쳐야 할 것: 메뉴 위치가 화면마다 다름 (가장 중요)

| 화면 | 메뉴 모양 |
|---|---|
| 01 홈 | 화면 **아래 캡슐 메뉴 바** |
| 03, 05, 06, 07, 08, 09 | 화면 **왼쪽 세로 메뉴(사이드바)** — 예전에 "블로그 같다"고 하신 형태 |
| 04 아티스트 상세 | **위쪽 가로 메뉴** |

→ 한 가지로 통일해야 합니다. **추천: 모든 화면에서 아래 캡슐 메뉴 바 + ≡ 버튼으로 02 전체 화면 메뉴.** 하위 페이지는 사이드바를 없애고 본문을 화면 전체 폭으로 씁니다.

## 4. 빠진 화면

### 1차 오픈에 꼭 필요 (디자인 추가 필요 또는 제가 같은 스타일로 맞춰 만들 것)

| 빠진 화면 | 왜 필요한가 |
|---|---|
| **홈 아래 섹션들**: NEW RELEASE · ARTISTS · **BUSINESS(필수)** · NEWS · NOTICE | 지금 홈은 첫 화면만 있고 아래로 내릴 수 없음. BUSINESS 섹션은 수익화 필수 |
| **하단(Footer)** | 회사 정보·사업자등록번호·개인정보처리방침·쿠키 정책·AI 표시 문구는 법적으로 필요 |
| **BUSINESS 개요 페이지** (`/business`) | 세 가지 방법 + 캠페인 빌더 바 + 함께한 브랜드 (보내주신 첫 이미지 구성) |
| **뉴스 상세(글 읽기) 페이지** | 목록에서 글을 누르면 열리는 화면 |
| **일반 소개 페이지 틀** | 회사 소개 · 연혁 · 오시는 길 · 탤런트 사용 계약 · 정책 페이지 등이 모두 이 틀을 씀 |
| **작업 사례 목록·상세** | BUSINESS 하위 메뉴 |
| **12개 언어 선택** | 디자인은 `EN / KR` 두 개뿐. 12개를 고르는 펼침 목록 필요 |
| **모바일 화면** | 01 홈과 02 메뉴는 모바일 대응이 전혀 없음. 캡슐 메뉴는 모바일에서 줄여야 함 |
| 작은 화면들 | 404 · 쿠키 동의 배너 · 견적/문의 "접수 완료" 화면 · 입력 오류 표시 |

> 위 화면들은 **새로 디자인하지 않아도** 지금 디자인의 색·글꼴·부품으로 제가 맞춰 만들 수 있습니다. 특히 원하시는 화면만 Variant로 추가로 뽑아 주세요.

### 2차·3차 오픈 (지금 없어도 됨)
JOIN US(크리에이터 모집·채용) · TRUST 페이지들 · INVESTORS의 나머지 탭(백서·로드맵·공시·감사·공식 주소·위험 고지)은 일반 소개 페이지 틀 + 07 토큰 화면 부품으로 만들 수 있습니다.

## 5. 내용 중 바꿔야 할 것

| 항목 | 문제 | 처리 |
|---|---|---|
| `AEON_01`, `AEON ENTERTAINMENT` | 디자인용 가짜 회사 이름 | **CUBIT ENTERTAINMENT 로고**(큐빗엔터로고.png)로 교체 |
| 가짜 HUD 문구 (`COORDS`, `SYSTEM_PROTOCOL`, `BUFFER 98.4%`, `VER 4.0.8`) | 장식용 | 분위기용으로 남기되 **실제 정보처럼 보이는 숫자는 제거** |
| CONTACT의 "AES-256 암호화", "응답 0.8초~24시간" | **사실이 아닌 보안·서비스 약속** | 삭제 (허위 표시가 될 수 있음) |
| CONTACT 동의 문구 "neural data" | 법적 동의 문구로 부적절 | 실제 개인정보 수집·이용 동의 문구로 교체 |
| 아티스트 상세의 조회수(12.4M) · 재생 시간 | 자동으로 가져오려면 YouTube API 필요 | 처음엔 빼고, 원하시면 나중에 추가 |
| 캠페인 빌더의 "$45,000+ 예상 금액" | 단가표를 정해야 보여줄 수 있음 | 결정 필요 (아래 6번) |
| 토큰 정보의 숫자 (총 발행량 10억, 배분 비율, 락업 표, 계약 주소) | 디자인용 가짜 값 | **실제 값은 관리자 화면에서 입력**, 공개 전 법률 검토 |
| 메뉴 하위 항목 (Vision, Team, XR Studio, **Stock Info** 등) | 사이트맵과 다름. 특히 우리는 주식이 아니라 코인 | 관리자 화면의 메뉴(사이트맵 기준)로 표시 |
| 외부 사진 (Unsplash) · 외부 영상 (Vimeo) | 디자인용 임시 자료 | 실제 아티스트 사진 · 계열사 소개 영상으로 교체 |

## 6. 정해 주셔야 할 것 (추천안 포함)

| 번호 | 질문 | 추천 |
|---|---|---|
| ① | 메뉴를 어떤 모양으로 통일할까? | **아래 캡슐 메뉴 + 전체 화면 메뉴** (3번 참고) |
| ② | 캠페인 빌더에서 예상 금액을 보여줄까? | **처음엔 숨기고 "견적 요청"만** (단가표가 정해지면 켜기) |
| ③ | 캠페인 빌더 용도 선택지 | 디자인대로 **디지털 광고 · TV·영상 · SNS · 옥외(OOH)** 4개로 변경 |
| ④ | 캠페인 빌더 지역 선택지 | 디자인대로 **전 세계 · 한국 · 북미 · 유럽 · 아시아태평양** + 직접 입력 |
| ⑤ | 문의 양식의 파일 첨부(최대 50MB) | **넣기** (저장소 연결 후, 사진·PDF·영상만 허용) |
| ⑥ | 아티스트 목록의 "레이블별 보기" | 계열사(레이블)를 등록하는 2차 작업 때 추가 |
| ⑦ | 홈 첫 화면 영상 | 계열사 소개 영상에서 **15~30초 하이라이트를 잘라 압축**해서 사용 (아래 7번) |

## 7. 계열사 6곳과 소개 영상

- 계열사: CUBITER · VIONA · ANIMA-X · EXIMAX · EXORA (+ CUBIT ENTERTAINMENT)
- 05 브랜드·레이블·계열사 화면에 **로고 + 소개 + 소개 영상**으로 넣습니다.
- 영상 크기가 **25~87MB**로 커서 그대로 홈에 틀면 느려집니다.
  - 홈 슬라이드용: 15~30초 하이라이트, 영상당 5MB 이하로 압축
  - 계열사 페이지: 전체 영상은 YouTube에 올리고 링크로 연결하거나, 압축본 사용
- 압축은 제가 영상 변환 프로그램(ffmpeg)을 설치해서 할 수 있습니다 (설치 허락 필요).

## 8. 기술적으로 제가 맞춰 넣을 것 (결정 필요 없음)

- 12개 언어: 글이 길어져도 깨지지 않게 크기 자동 조절 (아티스트 이름 8rem 고정 → 화면에 맞춰 줄어들게)
- 한국어·일본어·중국어·아랍어·힌디어·벵골어 글꼴 추가 (Inter · Space Mono는 영어 전용)
- **아랍어**: 글자 사이 간격(letter-spacing)을 넣으면 글자가 끊어져 보이므로 아랍어에서는 간격 효과를 끔 + 화면 좌우 반전
- 움직임 줄이기 설정을 켠 방문자에게는 입자·스캔라인 효과를 끔 (접근성)
- 디자인의 Tailwind · 아이콘을 외부 CDN 대신 사이트에 직접 포함 (속도 · 안정성)
