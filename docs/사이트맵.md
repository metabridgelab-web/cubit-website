# 홈페이지 사이트맵 · 페이지 뼈대 (v3)

> 기준: SM · JYP · YG 같은 대형 엔터 회사의 홈페이지 구조
> 범위: 메뉴 구조, 페이지 구성, 관리자 모드, 다국어 구조. 디자인은 별도로 정합니다.
> 표기: `[ ]` = 나중에 채울 내용 · **필수** = 빼면 안 되는 항목 (수익화 핵심)

### v3에서 바뀐 것
- BUSINESS를 **필수(수익화 핵심)**로 지정하고, 모든 섭외·광고 문의를 **캠페인 빌더**로 받도록 변경
- COMPANY에 **브랜드 · 레이블 · 계열사** 추가
- **INVESTORS (투자자 정보: 코인)** 메뉴 신설
- STUDIO를 **제작 과정 공개 · 기술 쇼케이스**로 강화
- 홈 메인 비주얼을 **옆으로 넘기는 영상 슬라이드**(JYP · CUBE 방식)로 변경

## 1. 전체 메뉴 구조: 사이드 메뉴

상단에 메뉴를 늘어놓지 않고, **옆에 세로 메뉴 블록**을 두어 섹션별로 나눕니다.

```
[로고]

ARTISTS
  가수 · 모델 · 배우 · 전문의

COMPANY
  회사 소개 · 연혁 · 브랜드·레이블·계열사 · 오시는 길

STUDIO
  제작 과정 공개 · 기술 쇼케이스

BUSINESS  ★필수
  개요 · 탤런트 사용 계약 · 브랜드 전속 AI 탤런트 제작 · 캠페인 빌더 · 작업 사례

INVESTORS
  프로젝트 개요 · 토큰 정보 · 백서 · 로드맵 · 공시 · 보안 감사 · 공식 주소 안내 · 위험 고지

NEWS
  뉴스 · 공지사항

TRUST
  AI 표시 원칙 · 데이터 원칙 · 사칭 신고

JOIN US
  크리에이터 파트너 모집 · 채용

CONTACT
─────────────
언어 선택 · SNS
```

### 사이드 메뉴 동작

| 화면 | 동작 |
|---|---|
| PC | 화면 왼쪽에 고정된 메뉴 블록. 섹션 이름을 누르면 하위 메뉴가 펼쳐짐 |
| 모바일 | 메뉴 버튼을 누르면 옆에서 열리는 서랍 메뉴 |
| 아랍어 | 오른쪽에서 왼쪽으로 쓰는 언어라 메뉴가 **오른쪽**으로 이동 (4장 참고) |

- 상단에는 로고와 언어 선택, 메뉴 버튼만 남깁니다.
- 메뉴 섹션과 항목은 관리자 모드에서 추가하고 순서를 바꿀 수 있게 만듭니다 (5장 참고).
- 사이드 메뉴 맨 아래에 **[캠페인 견적 받기]** 버튼을 항상 둡니다. 어느 페이지에서든 바로 견적 요청으로 갈 수 있게 하기 위해서입니다.

## 3. 페이지별 뼈대

### 3-1. HOME `/`

**① 메인 비주얼: 대표 영상 슬라이드 (화면 전체)**

화면 전체에 대표 영상을 띄우고, JYP · CUBE처럼 **옆으로 넘기며 여러 영상을 보여주는 슬라이드**로 만듭니다.

| 항목 | 내용 |
|---|---|
| 슬라이드 하나 | 영상 · 아티스트 이름 · 곡·작품 제목 · 발매일 · **[뮤직비디오 보기]** 버튼 |
| 넘기는 방법 | 좌우 화살표 · 하단 번호 표시 (예: `03 / 08`) · 모바일은 손가락으로 밀기 · 키보드 좌우 키 |
| 자동 넘김 | 영상이 끝나거나 정해진 시간이 지나면 다음 슬라이드로 (시간은 관리자 모드에서 설정) |
| 소리 | **음소거로 자동 재생.** 소리 켜기 버튼을 누르면 그 슬라이드는 자동 넘김을 멈춤 |
| 빠른 로딩 | 지금 보이는 슬라이드만 재생하고, 나머지는 대표 이미지만 불러둠 |
| 정렬 | 기본은 최신 발매 순. 관리자 모드에서 순서를 끌어서 바꿈 |
| 개수 | 5~10개 권장 (많으면 로딩이 느려짐) |

**영상 재생 방식: 둘 중 선택 (관리자 모드에서 둘 다 지원)**

| 방식 | 장점 | 단점 |
|---|---|---|
| A. YouTube 영상을 그대로 삽입 | 관리자는 링크만 붙여넣으면 됨 · 서버 용량을 쓰지 않음 | YouTube 로고와 조작 버튼이 일부 보임 · 광고가 나올 수 있음 · 슬라이드마다 YouTube를 불러와 느려질 수 있음 |
| B. 짧은 하이라이트 영상(15~30초)을 직접 올리고, 버튼을 누르면 YouTube 전체 영상으로 이동 | 화면이 깔끔함 · 광고 없음 · 슬라이드 전환이 빠름 | 영상 파일을 따로 만들어 올려야 함 |

> 슬라이드 방식에는 **B를 추천**합니다. 대형 엔터 사이트에서 흔히 쓰는 방식입니다.

**② 아래 순서**
1. **NEW RELEASE**: 최신 뮤직비디오 · 화보 카드
2. **ARTISTS**: 카테고리별 대표 아티스트 (가수 / 모델 / 배우 / 전문의 탭)
3. **BUSINESS 섹션 (필수)**: 3-5의 개요 페이지 내용을 그대로 축소해 노출 (세 가지 방법 + 캠페인 빌더 바 + 함께한 브랜드)
4. **NEWS**: 최신 뉴스 4개 + 더보기
5. **NOTICE**: 최신 공지 1~3개 (사칭 주의 같은 중요 공지 상단 고정)
6. 하단 (Footer)

> 홈의 각 섹션은 관리자 모드에서 보이기·숨기기와 순서 바꾸기가 가능하게 만듭니다. 단, **BUSINESS 섹션은 숨길 수 없게** 고정합니다.

### 3-2. ARTISTS `/artists`

**목록 페이지** `/artists/[카테고리]`
- 카테고리 탭: 가수 · 모델 · 배우 · 전문의
- 레이블로 거르기 (3-3의 레이블과 연결)
- 아티스트 카드: 대표 사진 · 이름

**상세 페이지** `/artists/[카테고리]/[이름]`

네 카테고리 모두 **같은 틀**을 씁니다.

| 항목 | 담을 내용 |
|---|---|
| 사진 | 대표 사진 1장 + 사진 모음(여러 장) |
| 정보 | 이름 · 생일 · 데뷔일 · 국적 · 소속 레이블 등 기본 정보 · 공식 SNS 링크 |
| 자기소개 | 아티스트 소개글 (12개 언어 번역 대상) |
| 뮤직비디오 | 해당 인물의 뮤직비디오 목록 (YouTube 링크) |
| **캠페인 견적 받기 (필수)** | 누르면 캠페인 빌더로 이동하고, 이 아티스트가 미리 선택되어 있음 |

- **정보 항목은 관리자 모드에서 추가할 수 있게** 만듭니다. 예: 모델에 "키", 배우에 "출연작", 전문의에 "전문 분야"
- 가수가 아닌 카테고리는 뮤직비디오 대신 출연 영상을 넣을 수 있게 합니다.

> **전문의 페이지 고지문**: "AI 캐릭터이며 실제 의사가 아닙니다. 진단·처방을 하지 않습니다." 감수한 실제 전문의의 이름과 자격도 함께 표시합니다. 공개 전 의료법 검토가 필요합니다.

- 팬에게는 볼거리가 되고, 기업 고객에게는 제작 능력을 보여주는 자료입니다.
- 제작 과정과 쇼케이스는 게시판처럼 계속 새 글을 올리는 구조로 만듭니다.

### 3-5. BUSINESS `/business` ★필수 (수익화 핵심)

회사의 매출이 들어오는 입구입니다. **섭외·광고 문의는 모두 캠페인 빌더 하나로 받습니다.** 메일로 따로 주고받는 섭외 문의는 두지 않습니다.

**개요 페이지** `/business` (홈 BUSINESS 섹션과 같은 내용)

```
FOR BRANDS
브랜드와 함께 일하는 세 가지 방법

01 탤런트 사용 계약
   소속 AI 탤런트를 광고·영상·SNS에 바로 기용.
   용도·기간·지역별 사용 허락 범위가 정해져 있어 계약이 빠름.

02 브랜드 전속 AI 탤런트 제작
   브랜드만을 위한 AI 탤런트를 세계관, 외모, 목소리부터 함께 제작.
   단기 캠페인부터 장기 IP까지.

03 캠페인 빌더
   탤런트와 조건을 직접 고르고 바로 견적 요청.
   섭외 메일을 주고받을 필요 없음.

[캠페인 빌더 바]
1 탤런트 선택 → 2 용도: 광고·영상·SNS → 3 기간·지역 → 4 사용 언어 → [캠페인 견적 시작]

함께한 브랜드: [브랜드 로고] [브랜드 로고] [브랜드 로고] ...      [작업 사례 보기]
```

**하위 페이지**

| 페이지 | 담을 내용 |
|---|---|
| 탤런트 사용 계약 `/business/licensing` | 계약 가능한 용도 (광고 · 영상 · SNS) · 사용 허락 범위 · 진행 절차 · [캠페인 견적 시작] |
| 브랜드 전속 AI 탤런트 제작 `/business/custom` | 제작 범위 · 진행 단계 · 제작 기간 · 사례 · [제작 견적 요청] |
| **캠페인 빌더** `/business/campaign` | 아래 참고 |
| 작업 사례 `/business/works` | 캠페인별 결과물 · 브랜드 · 사용 탤런트 · 성과 `[ ]` |

**캠페인 빌더 단계**

```
① 탤런트 선택 (여러 명 가능)
② 용도 선택: 광고 · 영상 · SNS · 기타
③ 기간·지역: 사용 기간 · 국가 또는 전 세계
④ 사용 언어: 12개 언어 중 선택
⑤ 회사 정보: 회사명 · 담당자 · 이메일 · 연락처 · 요청 사항 · 첨부파일
→ [견적 요청]
```

- 요청하면 접수 확인 메일이 자동으로 나갑니다.
- 관리자 모드 **견적 요청함**으로 들어오고, 진행 상태를 관리합니다: 접수 → 견적 발송 → 협의 → 계약 → 완료
- 선택: 관리자 모드에 단가표를 넣어 두면 **예상 금액 범위**를 바로 보여줄 수 있습니다.
- 나중에 확장할 수 있는 것: 온라인 계약 · 결제

### 3-6. INVESTORS `/investors` (투자자 정보: 코인)

대형 엔터 회사의 IR(투자자 정보) 메뉴 자리입니다. 주식 대신 **코인(토큰) 정보**를 담습니다.

> ⚠️ **꼭 지킬 것**
> - 아직 **상장 전**입니다. 상장 현황은 **"상장 예정"**으로만 표시하고, 상장 일정이나 거래소는 확정된 뒤에 올립니다.
> - **수익 보장, 가격 전망, "지금 사면 오른다" 같은 표현은 쓰지 않습니다.** 투자 권유로 보이면 법적 문제가 됩니다.
> - 한국 가상자산이용자보호법, EU MiCA(백서·마케팅 규정), 미국 증권 규제 등 **나라마다 규제가 다릅니다.** 일부 국가는 이 메뉴의 접속을 막아야 할 수도 있습니다.
> - **공개 전 가상자산 전문 법률 검토가 반드시 필요합니다.**

| 페이지 | 담을 내용 |
|---|---|
| 프로젝트 개요 `/investors` | 비전 · 토큰이 회사 서비스에서 쓰이는 곳 `[예: 팬 투표 · 굿즈 · 콘텐츠 이용]` |
| 토큰 정보 `/investors/token` | 토큰 이름·심볼 · 발행 총량 · 배분 비율 · 락업 일정 · 상장 현황 ("상장 예정") |
| 백서 `/investors/whitepaper` | 백서 PDF (언어별) · 버전 기록 |

## 4. 다국어: 12개 언어

### 4-1. 언어 목록

전 세계 사용 인구(모국어 + 제2언어 합계) 상위 10개 언어에 한국어와 일본어를 더했습니다. 일본어는 사용 인구로는 13위권이지만, K엔터의 핵심 시장이라 넣었습니다.

| 순서 | 언어 | 주소 | 쓰는 방향 |
|---|---|---|---|
| 1 | 한국어 (기본 언어) | `/ko` | 왼쪽 → 오른쪽 |
| 2 | 영어 | `/en` | 왼쪽 → 오른쪽 |
| 3 | 중국어 (간체) | `/zh` | 왼쪽 → 오른쪽 |
| 4 | 힌디어 | `/hi` | 왼쪽 → 오른쪽 |
| 5 | 스페인어 | `/es` | 왼쪽 → 오른쪽 |
| 6 | 아랍어 | `/ar` | **오른쪽 → 왼쪽** |
| 7 | 프랑스어 | `/fr` | 왼쪽 → 오른쪽 |
| 8 | 벵골어 | `/bn` | 왼쪽 → 오른쪽 |
| 9 | 포르투갈어 | `/pt` | 왼쪽 → 오른쪽 |
| 10 | 러시아어 | `/ru` | 왼쪽 → 오른쪽 |
| 11 | 인도네시아어 | `/id` | 왼쪽 → 오른쪽 |
| 12 | 일본어 | `/ja` | 왼쪽 → 오른쪽 |

> **참고**: 사용 인구 11위인 우르두어는 일본어로 바꾸면서 뺐습니다. 언어는 관리자 모드에서 켜고 끌 수 있게 만들기 때문에, 나중에 다시 넣거나 바꾸는 것도 쉽습니다.

### 4-2. 언어마다 글자 길이가 달라도 깨지지 않게

같은 문장도 언어마다 길이가 크게 다릅니다. 러시아어나 프랑스어는 한국어보다 훨씬 길어지기도 합니다. 그래서 다음 원칙을 지킵니다.

- **크기가 고정된 텍스트 상자는 쓰지 않습니다.** 글이 길어지면 상자가 자동으로 늘어나고 줄이 바뀝니다.
- **이미지 안에 글자를 넣지 않습니다.** 배너 문구도 이미지가 아니라 글자로 올려야 번역됩니다.
- 카드처럼 공간이 좁은 곳은 정해진 줄 수를 넘으면 "…"으로 줄입니다.
- 버튼은 글자 길이에 맞춰 너비가 늘어나게 합니다.
- 아랍어는 화면 전체를 좌우 반전합니다. 메뉴는 오른쪽, 글은 오른쪽 정렬로 바뀝니다. 슬라이드 넘기는 방향도 반대가 됩니다.
- 글꼴은 12개 언어의 문자를 모두 지원하는 글꼴(예: Google Noto 계열)을 씁니다. 그래야 글자가 깨지지 않습니다.

### 4-3. 번역 흐름 (관리자 모드)

관리자는 **한국어로 한 번만 쓰면** 됩니다.

```
① 한국어로 작성 → ② [저장] → ③ 11개 언어 자동 번역 → ④ 필요하면 언어별로 고쳐 쓰기 → ⑤ 게시
```

- 저장하면 자동 번역됩니다. 번역 서비스(DeepL, Google 번역, AI 번역 등)를 연결합니다.
- 언어마다 "자동 번역 / 검수 완료" 상태를 표시합니다.
- 고쳐 쓴 번역은 다음 자동 번역 때 덮어쓰지 않습니다.
- 한국어 원문을 바꾸면 다른 언어에 "원문 변경됨" 표시가 뜨고, 다시 번역 버튼을 누르면 됩니다.
- **용어집**: 아티스트 이름, 곡 제목, 회사 이름, 토큰 이름처럼 번역하면 안 되는 단어를 등록해 둡니다.
- **검수 필수 문서**: 위험 고지, 백서, 개인정보처리방침 같은 법적 문서는 자동 번역만으로는 게시되지 않게 막고, 검수 완료 후에만 게시합니다.
- 메뉴 이름, 버튼 글자 같은 사이트 고정 문구도 같은 방식으로 관리합니다.

## 5. 관리자 모드

### 5-1. 설계 원칙: 누구나 쉽게

| 원칙 | 구현 방법 |
|---|---|
| 모든 화면을 같은 방식으로 | 어느 메뉴든 **목록 → 새로 만들기 / 수정 → 저장**의 같은 흐름 |
| 필요한 것만 보이게 | 필수 항목만 먼저 보이고, 나머지는 "더보기"로 접어둠 |
| 끌어다 놓기 | 사진·파일은 끌어다 놓으면 업로드, 순서도 끌어서 바꾸기 |
| 실수해도 괜찮게 | 자동 임시저장 · 게시 전 미리보기 · 삭제는 휴지통으로 (30일 보관) · 수정 기록에서 되돌리기 |
| 예약 게시 | 날짜·시간을 정해 두면 자동 게시 · 게시 종료일도 설정 |
| 한국어 관리 화면 | 관리자 화면은 한국어로, 모바일에서도 사용 가능 |
| 권한 나누기 | 최고 관리자 / 편집자 / 번역 검수자 / 영업 담당자 / 공시 담당자 · 누가 무엇을 바꿨는지 기록 |
| 이중 승인 | 토큰 정보 · 공시 · 위험 고지는 **최고 관리자가 승인해야 게시** |

### 5-3. 확장성: 자료가 계속 늘어나도 문제없게

| 항목 | 방법 |
|---|---|
| 저장 공간 | 사진·파일은 **클라우드 저장소**에 보관 (AWS S3, Cloudflare R2 등). 용량 제한 없이 쓴 만큼만 비용을 냄 |
| 빠른 로딩 | CDN(전 세계 서버에 복사해 두는 서비스)으로 해외에서도 빠르게 표시 |
| 사진 자동 처리 | 원본을 올리면 화면 크기별로 줄인 사진을 자동으로 만들고 용량을 줄임 |
| 영상 | 긴 영상은 YouTube 링크로 연결해 서버 용량을 쓰지 않음. 홈 슬라이드용 짧은 영상만 직접 저장 |
| 코드 수정 없이 늘리기 | 카테고리 · 게시판 · 메뉴 · 언어 · 아티스트 정보 항목 · 레이블 · 슬라이드를 **관리자 화면에서 바로 추가** |
| 나중에 붙일 기능 | 온라인 계약·결제 · 코인 시세 위젯 · 거래소 목록을 미리 자리만 만들어 두고 필요할 때 켬 |
| 백업 | 매일 자동 백업 · 필요 시 날짜별 복원 |
