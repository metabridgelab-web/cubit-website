## 영상: YouTube + Cloudflare Stream

| 영상 종류 | 저장 위치 | 이유 |
|---|---|---|
| 뮤직비디오 | **YouTube** (링크 붙여넣기) | 이미 공식 채널에 있고, 사이트에서 재생해도 YouTube 조회수로 잡힘. 무료 |
| 홈 첫 화면 배경 · 회사·계열사 소개 · 메이킹 영상 | **Cloudflare Stream** (원본 파일 올리기) | 광고·YouTube 로고 없음. 원본(최대 30GB)을 올리면 여러 화질로 자동 변환. 중국 본토처럼 YouTube가 막힌 곳에서도 재생 |

- 관리자 화면에서 영상마다 "YouTube 링크" 또는 "파일 올리기" 중 하나를 고른다.
- 요금 (2026-10 기준): Stream 보관 1,000분당 월 $5, 재생 1,000분당 $1, 화질 변환 무료.
- 방문자가 크게 늘어 홈 영상 재생 요금이 부담되면, 해당 슬라이드만 YouTube로 바꿀 수 있다.
- 연결 시점: 인터넷에 올리는 단계(Cloudflare 계정 생성 후).
