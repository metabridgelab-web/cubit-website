# 인터넷에 올리기: 계정 만들기 단계별 안내

> 순서대로 하시면 됩니다. 각 단계가 끝나면 Claude에게 "N단계 끝났어"라고 알려 주세요. 연결과 확인은 Claude가 합니다.
> **비밀번호 · API 키 · 데이터베이스 주소는 채팅에 붙여넣지 마세요.** 넣을 곳(Vercel 환경 변수 또는 프로젝트의 `.env` 파일)을 매번 알려 드립니다.

## 전체 그림

| 서비스 | 하는 일 | 요금 (2026-10 기준, 가입 화면에서 다시 확인) |
|---|---|---|
| **GitHub** | 사이트 코드 보관 (Vercel이 여기서 가져가 배포) | 무료 (비공개 저장소) |
| **Vercel** | 사이트 서버 | **Pro 월 $20** (회사 사이트는 무료 Hobby 사용 불가 · 1분마다 번역·메일 작업을 돌리려면 Pro 필요) |
| **Neon** | 데이터베이스 (아티스트 · 글 · 접수함 등) | 무료로 시작, 정식 오픈 때 유료 전환 검토 |
| **Cloudflare R2** | 사진 · 영상 · PDF · 첨부 파일 저장소 | 10GB까지 무료, 이후 GB당 월 약 $0.015, 내려받기 비용 없음 |
| **Cloudflare Stream** | 홈 · 계열사 · 메이킹 고화질 영상 | 보관 1,000분당 월 $5, 재생 1,000분당 $1 |

이미 있는 것: Anthropic(번역) · Resend(메일) 키 → 그대로 씁니다.

## 1단계. GitHub (코드 보관소)

1. https://github.com 에서 회사 이메일로 가입합니다.
2. 오른쪽 위 **+** → **New repository**
   - Repository name: `cubit-website`
   - **Private** 선택
   - 아래 체크 상자(README 등)는 모두 **비워 둡니다**
   - **Create repository**
3. Claude에게 "1단계 끝났어, 저장소 주소는 https://github.com/아이디/cubit-website" 라고 알려 주세요.
4. Claude가 코드를 올릴 때 **GitHub 로그인 창**이 뜨면 대표님이 직접 로그인해 주세요.

## 2단계. Vercel (사이트 서버)

1. https://vercel.com → **Sign Up** → **Continue with GitHub** (1단계 계정으로)
2. 팀 이름을 정하고 **Pro** 요금제를 고릅니다 (결제 수단 등록).
3. **Add New… → Project** → `cubit-website` 저장소 옆 **Import**
4. 설정 화면에서 **아직 Deploy를 누르지 말고** Claude에게 "2단계 화면이야"라고 알려 주세요. 환경 변수를 같이 넣습니다.

## 3단계. Neon (데이터베이스) — Vercel 안에서 만들기

1. Vercel 프로젝트 화면 → **Storage** 탭 → **Create Database** → **Neon** → **Continue**
2. 지역(Region): **Washington, D.C., USA (East)** — Vercel 서버 기본 지역과 같은 곳이어야 빠릅니다.
3. 요금제: **Free**로 시작
4. 프로젝트에 연결하면 `DATABASE_URL`이 Vercel 환경 변수에 **자동으로** 들어갑니다. (직접 복사할 필요 없음)

## 4단계. Cloudflare (파일 저장소 R2 · 영상 Stream)

### 4-1. 가입
1. https://dash.cloudflare.com/sign-up 에서 회사 이메일로 가입합니다.
2. 도메인 추가 화면이 나오면 **건너뜁니다** (도메인은 마지막에 옮깁니다).

### 4-2. R2 저장소 만들기
1. 왼쪽 메뉴 **R2 Object Storage** → 처음이면 결제 수단 등록 후 **R2 구독** (10GB까지 무료)
2. **Create bucket** 두 번:
   - `cubit-media` — 사진 · 영상 · PDF (누구나 볼 수 있음)
   - `cubit-private` — 문의 첨부 파일 (공개하지 않음)
3. `cubit-media` → **Settings** → **Public access** → **R2.dev subdomain** → **Allow**
   - 나오는 주소(`https://pub-…r2.dev`)를 메모해 두세요. (공개 주소라 채팅에 알려 주셔도 됩니다)
   - 도메인을 Cloudflare로 옮긴 뒤에는 `media.cubitenter.com` 같은 주소로 바꿉니다.
4. 두 버킷 모두 **Settings → CORS Policy → Edit**에 아래를 붙여넣고 저장합니다.
   (브라우저가 파일을 저장소로 바로 올릴 수 있게 허락하는 설정. `프로젝트이름`은 2단계에서 정한 Vercel 주소로 바꾸세요)

```json
[
  {
    "AllowedOrigins": [
      "http://localhost:3000",
      "https://프로젝트이름.vercel.app",
      "https://cubitenter.com",
      "https://www.cubitenter.com"
    ],
    "AllowedMethods": ["GET", "PUT", "HEAD"],
    "AllowedHeaders": ["*"],
    "ExposeHeaders": ["ETag"],
    "MaxAgeSeconds": 3600
  }
]
```

5. R2 첫 화면 오른쪽 **Manage API tokens** (또는 **API → Manage API Tokens**) → **Create API token**
   - Permissions: **Object Read & Write**
   - Specify bucket(s): `cubit-media`, `cubit-private`
   - **Create** → 화면에 나오는 세 값은 **이 화면에서만** 보입니다:
     - Access Key ID
     - Secret Access Key
     - (위쪽 주소에 있는) Account ID
   - 이 값들은 채팅에 붙여넣지 말고, 5단계에서 Vercel 환경 변수에 바로 넣습니다.

### 4-3. Stream (고화질 영상)
1. 왼쪽 메뉴 **Stream** → 구독 (보관 1,000분당 월 $5)
2. **Upload** 로 영상을 올립니다 (홈 영상 · 계열사 소개 영상 등. 원본 그대로 올리면 여러 화질로 자동 변환).
3. 영상을 누르면 나오는 주소 `https://customer-XXXX.cloudflarestream.com/…` 에서 **XXXX** 부분이 "고객 코드"입니다 (공개 값이라 채팅에 알려 주셔도 됩니다).
4. 관리자 화면에서 영상 방식을 **Cloudflare Stream**으로 고르고, 영상의 **ID(32자리)** 를 붙여넣으면 됩니다.

## 5단계. Vercel 환경 변수 넣기

Vercel 프로젝트 → **Settings → Environment Variables** 에 하나씩 넣습니다 (Environment는 **Production**과 **Preview** 모두 체크).

| 이름 | 값 |
|---|---|
| `PAYLOAD_SECRET` | 아무도 모르는 긴 무작위 글자 (Claude가 만들어 드릴 수 있음) |
| `CRON_SECRET` | 또 다른 긴 무작위 글자 |
| `NEXT_PUBLIC_SERVER_URL` | `https://프로젝트이름.vercel.app` (도메인 연결 후 `https://www.cubitenter.com`) |
| `ANTHROPIC_API_KEY` | 지금 `.env`에 있는 값과 같게 |
| `RESEND_API_KEY` | 지금 `.env`에 있는 값과 같게 |
| `EMAIL_FROM_ADDRESS` | `no-reply@mail.cubitenter.com` |
| `EMAIL_FROM_NAME` | `CUBIT ENTERTAINMENT` |
| `R2_ACCOUNT_ID` | 4-2의 Account ID |
| `R2_ACCESS_KEY_ID` | 4-2의 Access Key ID |
| `R2_SECRET_ACCESS_KEY` | 4-2의 Secret Access Key |
| `R2_PUBLIC_BUCKET` | `cubit-media` |
| `R2_PRIVATE_BUCKET` | `cubit-private` |
| `R2_PUBLIC_URL` | 4-2의 `https://pub-…r2.dev` 주소 |
| `CF_STREAM_CUSTOMER_CODE` | 4-3의 고객 코드 (XXXX) |

`DATABASE_URL`은 3단계에서 자동으로 들어가 있습니다.

## 6단계. 첫 배포 — Claude가 확인

1. Vercel에서 **Deploy** (또는 Claude가 코드를 올리면 자동 배포)
2. 배포 중 데이터베이스 표가 자동으로 만들어집니다 (`payload migrate`).
3. `https://프로젝트이름.vercel.app/admin` 에서 **대표님이 직접** 첫 관리자 계정을 만듭니다 (첫 계정 = 최고 관리자).
4. Claude가 기본 데이터(메뉴 · 카테고리 · 시작용 페이지)와 계열사 영상을 넣고, 번역 · 메일 · 파일 올리기 · 영상 재생을 확인합니다.

## 7단계. 도메인 옮기기 (마지막)

모든 확인이 끝난 뒤, cubitenter.com을 Wix에서 새 사이트로 연결합니다. Claude가 그때 화면마다 안내합니다.
- Resend 메일 기록(`mail.cubitenter.com`)은 **지우면 안 됩니다.**
