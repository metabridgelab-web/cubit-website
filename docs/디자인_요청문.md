# Variant 디자인 요청문 · 섹션별

> 기준 문서: 사이트맵.md (v3)
> 사용법: 아래 영어 요청문을 Variant 입력창에 그대로 붙여넣으세요. 영어로 넣는 편이 결과가 안정적입니다.
> `[BRAND]`는 회사 이름으로, `[STYLE]`은 원하시는 분위기로 바꿔 넣으세요. 예: `dark luxury`, `clean white editorial`, `bold K-pop color`

---

## 0. 작업 순서 (중요)

1. **H2 메인 비주얼부터** 뽑아서 마음에 드는 스타일을 하나 고릅니다.
2. Variant의 **Style Dropper**(스타일 스포이트)로 그 스타일을 찍어서, 나머지 섹션에도 같은 스타일을 적용합니다.
3. 그래야 섹션마다 따로 뽑아도 한 사이트처럼 보입니다.

### 모든 요청문 끝에 붙일 공통 조건

```
Entertainment agency website, [STYLE] style. Text containers must grow with content (site supports 12 languages, text length varies). No text baked into images. Desktop 1440px wide.
```

## 고를 때 확인할 것

- [ ] 모든 섹션이 **같은 스타일**로 보이는지 (Style Dropper 사용)
- [ ] 글자가 **사진 위가 아니라 글자로** 들어가 있는지 (번역 가능 여부)
- [ ] 텍스트 칸이 좁게 고정되어 있지 않은지 (긴 언어 대비)
- [ ] BUSINESS 섹션과 캠페인 견적 버튼이 **눈에 잘 띄는지**
- [ ] 모바일 화면에서도 무너지지 않는지 (Variant에서 모바일 버전도 함께 확인)
