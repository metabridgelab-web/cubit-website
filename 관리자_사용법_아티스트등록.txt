관리자 화면 사용법 ① 아티스트 등록하기
(2026-10-25 작성 · 뉴스 · 작업 사례 · 페이지도 같은 방식)

관리자 화면: https://cubit-website-three.vercel.app/admin
(도메인을 옮긴 뒤에는 https://www.cubitenter.com/admin)


====================================================================
먼저 알아 둘 3가지
====================================================================

1) 영어로 쓴다
   - 화면 오른쪽 위 "locale: English" 가 English 인 상태에서 쓰고 저장한다.
   - 저장하면 나머지 11개 언어로 자동 번역된다 (1~2분).
   - 이름은 번역하지 않고 모든 언어에서 그대로 보인다.

2) "게시"를 눌러야 사이트에 보인다
   - 오른쪽 위 버튼이 두 개: [초안 저장] / [변경 사항 게시]
   - 초안 저장 = 관리자만 보임. 변경 사항 게시 = 방문자에게 보임.
   - 게시 전에 확인하기: [초안 저장] → 오른쪽 위 [미리보기] → 새 탭에 실제 사이트 모양으로 열린다.
     화면 아래 "미리보기 중" 띠가 보이면 초안을 보고 있는 것. 확인이 끝나면 [미리보기 끝내기].
     (미리보기는 저장한 초안을 보여 준다. 고친 뒤에는 꼭 [초안 저장]을 먼저 누른다.)
     아티스트 · 작업 사례 · 페이지에 있다.

3) 사진 · 영상은 끌어다 놓으면 끝
   - 파일은 Cloudflare R2 저장소로 바로 올라간다 (한 파일 최대 50MB).
   - 사진은 화면 크기별로 자동으로 줄여 저장된다.
   - 뮤직비디오는 파일이 아니라 YouTube 주소만 붙여넣는다.


====================================================================
아티스트 등록 순서
====================================================================

[1] 관리자 화면 로그인 → 첫 화면 "바로가기"의 [아티스트 추가]
    (또는 왼쪽 메뉴 아티스트 관리 → 아티스트 → 오른쪽 위 "새로 생성")

[2] "기본 정보" 탭
    - 이름 (필수): 예) LUNA V
    - 카테고리 (필수): 가수 · 모델 · 배우 · 전문가 중 고르기. 여러 개 가능.
    - 장르: 고른 카테고리의 장르만 보인다 (가수 → K-Pop · Rock · Jazz … 20개). 여러 개 가능.
        → 사이트의 가수 목록에 "장르" 선택 상자가 생기고, 고른 장르의 가수만 보인다.
        → 장르 목록 자체는 왼쪽 메뉴 "아티스트 관리 → 장르"에서 추가 · 이름 변경 · 순서 변경(끌어서).
    - 생일 / 데뷔일 / 국적
    - 추가 정보: "+ 추가" → 항목 / 내용
        예) Height / 168 cm,  Specialty / Dermatology,  Filmography / Neon Horizon (2026)
    - 공식 SNS: "+ 추가" → 플랫폼(Instagram · YouTube · TikTok …) / 주소(https://…)

[3] "사진" 탭
    - 대표 사진 (목록용, 필수): 아티스트 목록 · 홈 화면 카드에 나오는 사진.
        세로 사진(3:4) 추천, 가로 1200픽셀 이상.
        칸에 파일을 끌어다 놓거나 [새로 생성]을 누른다. (이미 올린 사진은 [기존 항목 중 선택])
        사진 창이 열리면 "대체 텍스트"에 짧은 설명을 쓴다 (예: LUNA V profile photo)
        → 화면 낭독기와 검색엔진용. 저장.
    - 상세 페이지 사진: 아티스트를 눌렀을 때 상세 페이지 맨 위에 크게 나오는 사진.
        비우면 대표 사진이 대신 나온다. 크고 선명한 사진 추천.
    - 사진 모음: 여러 장 한꺼번에 올릴 수 있다. 상세 화면 "사진" 부분에 나온다.

[4] "자기소개" 탭
    - 글 상자에 자유롭게 쓴다. 굵게 · 제목 · 목록 · 링크 가능.

[5] "뮤직비디오" 탭
    - "+ 추가" → 제목 / YouTube 주소 / 공개일 / 가사
    - 가사: 넣으면 영상 아래에 "가사 보기" 버튼이 생긴다. 번역하지 않고 모든 언어에서 그대로 보인다.
      빈 줄로 절(1절 · 후렴 등)을 나누면 읽기 좋다.
    - 주의: 화면 오른쪽 위 locale 이 English 인 상태에서 넣는다.
      한국어 상태에서 제목을 넣으면 다른 언어에서는 제목이 비어 보인다.
    - YouTube 주소 예: https://www.youtube.com/watch?v=xxxxxxxx
    - 위에 있을수록 먼저 보인다 (줄 왼쪽 손잡이로 끌어서 순서 변경).
    - 가장 최근 공개일 영상들은 홈 화면 "New Release"에도 자동으로 나온다.

[6] 오른쪽 옆 칸 (사이드바)
    - 홈 화면에 노출: 체크하면 홈 "Artists" 부분에 나온다.
    - 노출 순서: 숫자가 작을수록 앞에.
    - 주소(slug): 이름으로 자동으로 만들어진다 (예: luna-v). 보통 그대로 둔다.

[7] [초안 저장] → [미리보기]로 확인 → 오른쪽 위 [변경 사항 게시]
    - 아직 공개 전이면 [초안 저장]만 눌러 두고 나중에 게시해도 된다.


====================================================================
그룹 등록하기 (예: 4인조 걸그룹)
====================================================================

 순서: 멤버를 먼저 개인으로 등록 → 그룹을 등록하면서 멤버를 연결

[A] 멤버 등록
    - 위 [1]~[7] 순서 그대로, "유형"은 [개인 (솔로 · 그룹 멤버)]
    - 멤버 개인 사진 · 프로필 · 자기소개 · 개인 영상(솔로 활동)을 넣는다.
    - 멤버는 사이트 목록에 그룹으로만 보인다.
      개인으로도 목록에 보이게 하려면 오른쪽 옆 칸 "그룹과 따로 목록에도 표시"를 체크.

[B] 그룹 등록
    - [아티스트 추가] → "유형"을 [그룹]으로
    - 이름 · 카테고리(가수) · 장르 · 데뷔일
    - "멤버" 칸에서 [A]에서 등록한 멤버를 고른다. 끌어서 순서 변경 (사이트에 이 순서대로 나옴).
    - 사진 탭: 그룹 대표 사진(목록용) · 상세 페이지 사진(단체 사진 추천)
    - 자기소개: 그룹 소개 / 뮤직비디오: 그룹 뮤직비디오
    - [변경 사항 게시]

[C] 사이트에서 보이는 모습
    - 아티스트 목록: 그룹 카드 ("GROUP · 04")
    - 그룹 상세: 그룹 소개 · 뮤직비디오 + "멤버" 카드 → 누르면 멤버 상세
    - 멤버 상세: "Member of 그룹이름" 링크 + 같은 그룹의 다른 멤버
    - 캠페인 빌더: 그룹 바로 아래에 멤버가 "↳ 그룹이름"으로 이어서 보인다.
      브랜드가 그룹 전체를 고를 수도, 멤버 한 명만 고를 수도 있다.
    - 멤버 쪽 관리자 화면에는 "소속 그룹"이 자동으로 표시된다 (따로 입력할 필요 없음).


====================================================================
게시한 뒤 확인
====================================================================

[8] 번역 확인 (1~2분 뒤)
    - 오른쪽 옆 칸 "번역 상태"에 언어마다 상태가 보인다.
        번역 대기 → 자동 번역 이 되면 끝.
        번역 실패 가 있으면 상태를 "다시 번역"으로 바꾸고 저장.

[9] 사이트에서 보기
    - https://cubit-website-three.vercel.app/ko/artists  (한국어 화면)
    - 언어를 바꾸려면 사이트 오른쪽 위 언어 선택.


====================================================================
번역을 직접 고치고 싶을 때 (예: 한국어 자기소개를 다듬기)
====================================================================

 - 화면 오른쪽 위 "locale: English" → 한국어 로 바꾼다.
 - 그 언어의 내용이 나온다. 고치고 [변경 사항 게시].
 - 그 언어는 "검수 완료"로 표시되어 자동 번역이 덮어쓰지 않는다.
 - 나중에 영어 원문을 바꾸면 그 언어는 "원문 변경됨"으로 바뀐다.
   (자동으로 덮어쓰지 않는다. 다시 확인하고 고치거나, 상태를 "다시 번역"으로 바꾸고 저장)


====================================================================
캠페인 빌더와의 관계
====================================================================

 - 아티스트를 게시하면 캠페인 빌더 1단계(아티스트 선택)에 자동으로 나온다.
 - 아티스트 상세 화면의 견적 버튼(Get a campaign quote with this artist)을 누르면
   그 아티스트가 미리 선택된 채로 캠페인 빌더가 열린다.
 - 전문가(Experts) 카테고리 아티스트 화면에는 "실제 자격을 가진 전문가가 아님" 안내가 자동으로 붙는다.


====================================================================
다른 내용도 같은 방식
====================================================================

 - 뉴스 · 공지:      게시판 관리 → 게시글
                     (예약 게시: 게시 버튼 옆 ▾ → [발행 일정]에서 날짜 · 시간 고르기)
 - 작업 사례:        비즈니스 → 작업 사례
 - 회사 소개 등:     페이지 관리 → 페이지 ([Replace …] 표시 글 바꾸기)
 - 계열사:           회사 소개 → 레이블 · 브랜드 · 계열사
 - 회사 정보 · SNS:  사이트 설정
 - 홈 영상:          홈 관리 → 메인 슬라이드
