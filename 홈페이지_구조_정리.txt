1. 전체 구조
====================================================================

[디자인과 기능]
 - 색, 글꼴, 배치, 움직임, 신청 양식, 자동 번역 · 메일 같은 동작
 - 코드로 만든다. 바꾸고 싶으면 Claude에게 말하면 된다.
 - 저장 위치: GitHub(코드 보관) → Vercel(사이트 서버)
 - GitHub에 올리면 Vercel이 자동으로 다시 배포한다 (1~2분)

[글자]
 - 관리자 화면에서 직접 고친다.
 - 저장 위치: Neon (데이터베이스)
 - 영어로 쓰고 저장하면 나머지 11개 언어로 자동 번역된다.

[사진 · 영상 · PDF]
 - 관리자 화면에서 직접 올린다.
 - 저장 위치: Cloudflare R2 (파일 저장소)

2. 사진과 영상은 어떻게 저장되나
====================================================================

 - 대표님 입장에서는 "그냥 업로드". 관리자 화면에 끌어다 놓으면 끝.
 - 실제로는 다른 서버(Cloudflare R2)에 저장되고, 사이트가 거기서 끌어온다.
   · 올리는 순간 파일이 사이트 서버를 거치지 않고 R2로 바로 간다 → 큰 파일도 올라간다.
   · 방문자도 R2에서 바로 받아 보므로 빠르고, 사이트 서버에 부담이 없다.
   · 사진은 올리면 화면 크기별(작게 · 중간 · 크게)로 자동으로 줄여 따로 저장된다.
 - 예외
   · YouTube (뮤직비디오): 파일을 올리지 않고 주소만 붙여넣는다. 영상은 YouTube에 있다.
   · Cloudflare Stream (나중에 연결하면): Cloudflare 화면에서 영상을 올리고,
     관리자 화면에는 영상 ID(32자리)만 붙여넣는다.


====================================================================
3. 디자인은 바꿀 수 없나?
====================================================================

 - 관리자 화면에서는 디자인을 바꿀 수 없다.
 - 하지만 영원히 못 바꾸는 것은 아니다. Claude에게 말하면 코드를 고쳐 몇 분 안에 반영된다.
 - 관리자 화면에서 바꿀 수 있는 "화면 구성" 요소도 있다.
   · 오른쪽 위 메뉴의 항목 · 순서 · 숨기기
   · 홈 아래 섹션의 순서 · 숨기기 (BUSINESS는 숨길 수 없음)
   · 홈 영상 슬라이드의 순서 · 넘김 속도 · 노출 기간
   · 페이지 안 블록 순서 (글 · 사진 · 영상 · 연혁 · 오시는 길 · 버튼)
   · 계열사 · 스튜디오 · 공고 카드의 순서 (목록에서 끌어서)
   · 사이트에 보일 언어 켜고 끄기, INVESTORS 공개 스위치

4. 관리자 화면으로 할 수 있는 범위
====================================================================

[직접 할 수 있는 것]
 - 글 · 사진 · 영상 추가, 수정, 삭제
   · 아티스트, 뉴스 · 공지(예약 게시 포함), 작업 사례
   · 회사 소개 · 연혁 · 정책 같은 페이지
   · 레이블 · 브랜드 · 계열사, 스튜디오, 모집 · 채용 공고, 공시
   · 투자자 정보, 사이트 설정(회사 정보 · SNS), 버튼 같은 고정 문구
 - 번역 고치기: 자동 번역된 글을 언어별로 고치고 "검수 완료"로 잠그기
   (위쪽 언어 선택을 바꾸면 그 언어 내용이 나온다)
 - 접수함: 견적 요청 · 문의 · 사칭 신고 · 지원서 확인, 처리 상태 바꾸기
 - 직원 계정 만들기, 권한 나누기 (편집자 · 번역 검수자 · 영업 담당 · 공시 담당)

[범위가 정해진 것]
 - 페이지 블록은 6종류만 (글 · 사진 · 영상 · 연혁 · 오시는 길 · 버튼).
   표 · 가격표 같은 새 모양은 코드가 필요하다.
 - 캠페인 빌더 선택지 개수(용도 4 · 지역 5 · 언어 15)와 문의 유형 개수는 고정.
   이름과 설명만 바꿀 수 있다.
 - 새 페이지 주소는 정해진 위치에만 생긴다: /about/… /business/… /legal/… /trust/…

[코드가 필요한 것 → Claude에게 요청]
 - 색 · 글꼴 · 배치 · 애니메이션 · 카드 모양 같은 디자인 전체
 - 새 기능, 새 종류의 페이지, 새 입력 칸
 - 13번째 언어 추가
 - 알림 메일의 형식
 - "COMPANY // PROFILE" 같은 작은 영어 장식 표시

[한 줄 요약]
 사이트의 틀(디자인 · 기능)은 코드라서 Claude와 함께 바꾸고,
 그 틀 안의 내용(글 · 사진 · 영상)과 순서는 관리자 화면에서 언제든 바꾼다.
